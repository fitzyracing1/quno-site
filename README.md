# quno-site

Static landing page for **Quno**: official and on-chain data for bots, paid per call over
x402 (USDC on Base). Served by GitHub Pages at https://fitzyracing1.github.io/quno-site/.

- `index.html`, `style.css`: the page (no JavaScript, no tracking)
- `og.png`: 1200x630 Open Graph / Twitter card image, generated by `og.py` (Pillow)

The API itself lives at https://quno-production.up.railway.app (catalog: `/v1/catalog`).
The 24h market stats on the page are baked in with their date; refresh them from
`/v1/x402/market/summary`.
