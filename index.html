How to pay (x402)

  1. Call any paid route. Quno answers HTTP 402 with a PAYMENT-REQUIRED header: base64 JSON with the price, asset (USDC on Base), and the address to pay.
  2. Your x402 client signs a USDC authorization for that exact amount and retries with a PAYMENT-SIGNATURE header. No account and no API key.
  3. The Coinbase CDP facilitator settles on Base, and Quno returns 200 with the JSON plus a PAYMENT-RESPONSE header holding the transaction hash.
$ curl -i https://quno-production.up.railway.app/v1/weather/zip/02740
HTTP/2 402
content-type: application/json
payment-required: eyJ4NDAyVmVyc2lvbiI6MiwiZXJyb3IiOiJQYXltZW50IHJlcXVpcmVkIi...

{"error":"Payment required"}
